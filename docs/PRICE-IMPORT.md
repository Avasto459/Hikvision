# Каталог из прайс-листов

**Цена в прайсе — закупочная в $.** Розница считается автоматически (`lib/pricing.ts`, классы `PriceCalculator`, `TiandyMarkup`, `StandardMarkup`):

| Бренд | Формула |
|---|---|
| TIANDY | $ × 10 × 1.05 |
| все остальные | $ × 10 × 1.15 |

Курс 1 $ = 10 TJS, итог округляется до целого сомони. Закупочная цена (в сомони, без наценки) записывается в `offers_stock.purchasePrice`.

## Что где лежит
- `data/price-catalog.json` — 1258 позиций из 4 xlsx и 3 PDF (бренд, модель, цена в $, остаток, категория).
- `public/catalog/` — фото, извлечённые из самих прайс-листов (697 шт.). Позиции без фото получают заглушку категории (`public/products/*.svg`).
- `data/hasi.db` — уже содержит импортированный каталог.
- `scripts/import-price-lists.mjs` — повторный/боевой импорт: `npm run catalog:import` (в Turso, если заданы `TURSO_*`) или `npm run catalog:import -- --local`.

Остаток: если он был в файле (Dahua) — берётся из файла; для Hikvision/TIANDY/Ruijie остатков в прайсах нет, поставлено 10 шт. — поправьте в админке → «Дилеры и склад».
Товары из прайсов помечены `sourceUrl = 'price-list'` — `npm run seed` / `prebuild` (синхронизация с hasi.tj) их не удаляет.

## Витрина после входа
Дилер и дистрибьютор после входа попадают в `/distributor/catalog`: поиск, категории, бренды, сортировка, «Показать ещё». Дилер собирает заказ прямо из каталога.
