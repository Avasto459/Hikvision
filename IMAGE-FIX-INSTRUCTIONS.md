# HASI Market — автоматическое восстановление фото товаров

1. Распакуйте архив и откройте папку проекта в VS Code.
2. Если у вас уже есть свой `.env.local`, скопируйте его в корень проекта из своей прежней папки. Не публикуйте этот файл и не отправляйте его посторонним.
3. Установите зависимости, если нужно:
   `npm install`
4. Запустите поиск и загрузку фотографий:
   `npm run catalog:images -- --limit=1500`
5. Дождитесь строки `Готово`. Скрипт сохраняет загруженные файлы в `public/catalog/` и обновляет `data/hasi.db`; товары и заказы не удаляются.
6. Перезапустите приложение: остановите `npm run dev` клавишами `Control+C`, затем снова выполните `npm run dev`.

Скрипт обрабатывает товары с общей SVG-заглушкой, ищет изображения по бренду и модели через Bing Images и сохраняет найденные файлы локально. Если поиск не дал пригодного файла, ставит резервную интернет-картинку камеры. Результаты поиска надо визуально проверить: поисковая система иногда может подобрать изображение похожей, но не идентичной модели.

Скрипт по умолчанию меняет только локальную базу `data/hasi.db`, а не удалённую базу Turso. Перед запуском желательно сделать копию `data/hasi.db`.
